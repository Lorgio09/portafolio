## Proyectos incluidos

- **[Alerta Médica Bolivia](https://github.com/CodeWithElias/hackathon-ai)**: plataforma web para reportar emergencias médicas, con GPS, análisis de fotos con IA y despacho de ambulancias.
- **App de reportes urbanos**: app Android (Kotlin + Jetpack Compose) para que los ciudadanos reporten baches y daños en las calles.
- **Piraí Store**: sistema de ventas e inventario que usa a diario un negocio real.

## Hecho con

React 19, Vite y Tailwind CSS 4. Es un sitio estático, sin backend.

## Correr localmente

```bash
npm install
npm run dev
```
